# Nilesh Bandhiya - Portfolio Website 🚀

Welcome to my personal portfolio website! This project showcases my skills, experience, and the work I've done as a Full Stack Developer.

---

## 🛠️ Built With

- **React** & **TypeScript**
- **Three.js** / **React Three Fiber** (for 3D elements)
- **GSAP** (for animations)
- **Vite** (build tool)

---


## 🛠️ Instructions

I have modified the GSAP Club plugins using trial versions.  
⚠️ Note: Trial plugins cannot be used for production or hosting.

For official GSAP Club plugins, refer here:  
https://gsap.com/docs/v3/Installation/

---

## ⚙️ Tech Stack

React • TypeScript • GSAP • Three.js • WebGL • HTML • CSS • JavaScript
